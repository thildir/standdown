# Changelog

## 0.1.0
- First release.
- A small movable box that counts down your PvP flag (`PvP 4:32`).
- Shown only while a flag timer is running. Turns green for the last minute.
- `/standdown` lists the commands: `unlock`, `lock` and `reset`.
- A dummy box is shown while the box is unlocked and no timer is running.
